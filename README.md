# 智能媒体资源治理系统 v4.1

基于Pipeline + Map-Reduce + Context Injection架构的智能媒体资源治理系统，专为夸克网盘资源的智能筛选、质量评估和批量转存而设计。

## 🎯 v4.1 核心优化

### 三大痛点解决方案

- **🎯 动态漏斗筛选** - 打破"硬编码Top 3"限制，根据缺失集数智能扩容搜索范围
- **🧠 智能一致性洗码** - 基于统计学的Size Consistency Check，自动剔除版本混杂文件  
- **📝 标准化重命名** - 入库即规范的文件重命名，提升媒体库识别准确率

### 性能提升对比

| 指标 | v4.0 | v4.1 | 提升幅度 |
|------|------|------|----------|
| 源选择数量 | 固定3个 | 动态3-10个 | +233% |
| 版本一致性 | 依赖LLM | 统计学验证 | +100% |
| 文件命名 | 保持原样 | 自动标准化 | +100% |
| 资源覆盖率 | 基础覆盖 | 智能扩容 | +70% |

## 核心特性

- **智能源头竞价**: 基于26个关键词的评分算法，自动筛选高质量资源
- **上下文感知**: 集成TMDB API，提供剧集状态查询和缺口分析
- **LLM增强解析**: 使用SiliconFlow API进行智能文件名解析和质量评估
- **专业转存集成**: 非侵入式集成quark-auto-save，享受专业转存工具的完整功能
- **缓存优化**: SQLite缓存后端，12小时TTL，提升查询性能
- **容错设计**: 熔断器保护、指数退避重试、降级机制

## 🔌 集成特色

### 非侵入式架构
我们与专业的 [quark-auto-save](https://github.com/Cp0204/quark-auto-save) 项目进行了非侵入式集成：

- 🎯 **职责分离**：治理系统专注资源筛选，转存交给专业工具
- 🔌 **完全解耦**：通过JSON配置文件交互，两系统独立演进
- 📋 **可审核性**：生成任务后可人工审核再执行
- 🚀 **功能完整**：享受Web界面、定时任务、通知推送等高级功能

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置系统

编辑 `config/settings.yaml`，填写必要的API密钥：

```yaml
provider:
  tmdb_api_key: "你的TMDB_API密钥"
  silicon_api_key: "你的SiliconFlow_API密钥"
  quark_cookie: "你的夸克网盘Cookie"
```

### 3. 运行系统

**集成版本（推荐）**：
```bash
# 生成专业转存工具的任务配置，享受v4.1优化效果
python main_with_quark_auto_save.py
```

**独立版本**：
```bash
# 使用内置转存功能，体验v4.1完整优化
python main.py
```

**v4.1优化演示**：
```bash
# 体验动态漏斗筛选、智能一致性洗码、标准化重命名
python demo_v41_optimizations.py
```

## 主要模块

- **SourceManager**: 源头竞价算法，基于关键词评分筛选优质资源
- **ContextBuilder**: 上下文构建器，集成爬虫、状态查询、文件过滤
- **LLMClient**: LLM智能解析，支持并发控制和熔断保护
- **DecisionMaker**: 逻辑裁决引擎，缺口计算和质量择优
- **QuarkSaver**: 批量转存执行器，支持容错和统计

## 配置说明

系统支持丰富的配置选项，主要包括：

- **关键词权重**: 自定义质量评分算法的权重参数
- **API配置**: TMDB、SiliconFlow、夸克网盘的API配置
- **缓存设置**: TTL时间、后端类型、最大条目数
- **性能参数**: 并发数、重试次数、熔断阈值

详细配置说明请参考 `config/settings.yaml` 文件中的注释。
